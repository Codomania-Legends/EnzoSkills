# 🚀 EnzoSkills

EnzoSkills is a modern, structured learning path dashboard designed to help users track coding skills, monitor academic progress, and visualize their technical growth. Built with a focus on seamless responsiveness and modern UI/UX principles, the application serves as a centralized hub for guided learning and skill management.

## ✨ Key Features

- **Structured Learning Paths:** Comprehensive dashboards to track tech stacks, languages, and core computer science concepts.
- **Progress Tracking & Analytics:** Visual feedback loops to monitor skill acquisition and completion rates.
- **Modern Responsive Design:** Fully optimized across mobile, tablet, and desktop views using fluid layouts.
- **Interactive Technical Components:** Clean, animated, and state-driven interfaces for smooth user engagement.

---

## 🛠️ Tech Stack & Architecture

### Frontend & Styling
- **React.js:** Core framework for component-based UI development.
- **Tailwind CSS & Bootstrap:** Employed for highly responsive, modern, and utility-first styling (utilizing mobile-first breakpoints like `sm` and `md` to guarantee perfect cross-device scaling).
- **GSAP (GreenSock Animation Platform):** Leveraged for high-performance, smooth interface transitions and interactive visual reveals.

### Backend & Database (MERN Ecosystem)
- **Node.js & Express.js:** Robust server-side framework for handling RESTful API routing and business logic.
- **MongoDB:** Flexible, document-based NoSQL database for structured data storage (users, paths, and skill modules).
